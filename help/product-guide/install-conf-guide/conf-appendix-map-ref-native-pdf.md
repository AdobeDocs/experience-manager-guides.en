# Configure appendix rendering for map references in Native PDF output

In Native PDF output, topics referenced in a submap inside an `<appendix>` element can render as chapters instead of appendices. By default, Experience Manager Guides classifies map references by element name, and that information is lost once the maps are flattened during processing.

Use this setting to classify map references using the `class` attribute generated by DITA-OT instead. Topics in an appendix submap then render as appendices.

>[!NOTE]
>
>This setting changes how map references are classified. It is disabled by default. Enable it only if your content places topics in a submap within an `<appendix>` and you see them rendered as chapters in Native PDF output.

## When to use this configuration

Consider the following example of a book map:

- An `<appendix>` element references topics directly. These topics are rendered as appendices in the generated PDF.
- Another `<appendix>` element references a submap, and the submap references topics using `<topicref>`.

Without this configuration, topics from the first appendix are rendered as appendices, but topics from the submap are rendered as chapters. Only the topics are published; the submap itself is used for hierarchy and does not appear in the output.

## Configure the setting

The following tabs provide instructions to configure this setting based on your Experience Manager Guides setup: Cloud Service or On-Premise.

>[!BEGINTABS]

>[!TAB Cloud Service]

1. Use the instructions given in [Configuration overrides](../install-conf-guide/download-install-config-override.md) to create the configuration file.

2. In the configuration file, provide the following (property) details:

    | PID                                     | Property Key                     | Property Value                |
    | --------------------------------------- | -------------------------------- | ----------------------------- |
    | `com.adobe.fmdita.config.ConfigManager` | `guides.publish.config` | **Default value:** “false”    |

3. Set the value to `true` to enable the setting, and deploy the configuration using Cloud Manager.

>[!TAB On-Premise]

1. Open the Adobe Experience Manager Web Console Configuration page.

    The default URL to access the configuration page is:

    ```http
    http://<server name>:<port>/system/console/configMgr
    ```

2. Search for and select the *com.adobe.fmdita.config.ConfigManager* bundle.

3. Select the setting **Guides Publish Config** (`guides.publish.config`) to enable it. By default, the setting is disabled.
    
4. Select **Save**.

>[!ENDTABS]
