# MCP - Expanding access to governed technical content

Learn how Model Context Protocol (MCP) enables AI-powered experiences to securely interact with AEM Guides through natural-language requests while respecting existing AEM access controls and permissions. In this session, we explain the MCP architecture, configuration, authentication, and security model, demonstrate currently supported capabilities, and explore practical use cases, current boundaries, and key considerations. It also covers deployment considerations for AEM as a Cloud Service and On-Prem/AMS environments, demonstrate how MCP-enabled clients can connect with AEM Guides, and discuss where MCP fits alongside Adobe’s broader AI capabilities.


## Session overview

In this session, you will learn how to to Setup, Configure, Use AEM Guides MCP
